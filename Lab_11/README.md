# Лабораторна робота №11: Декларативний запуск мульти-контейнерного застосунку (Docker Compose)

Ознайомлення з Docker Compose для опису та запуску мульти-контейнерних сервісів. Проєкт містить веб-застосунок (`app` на Python/Flask) та in-memory сховище (`redis`), об'єднані спільною мережею із прокиданням порту `8080:8080` та контролем черговості запуску через `depends_on`.

---

### Команди для виконання та тестування

```bash
# 1. Перевірка валідності та коректності синтаксису конфігураційного маніфесту
docker-compose config

# 2. Декларативне створення мережі та запуск обох сервісів у фоновому (detached) режимі
docker-compose up -d

# 3. Перевірка статусів контейнерів та зіставлення мережевих портів
docker-compose ps

# 4. Тестування HTTP-відповіді застосунку та інкременту лічильника в Redis
curl http://localhost:8080
curl http://localhost:8080

# 5. Перегляд системних логів обох сервісів і перевірка відсутності помилок
docker-compose logs

# 6. Коректна зупинка процесів і видалення контейнерів разом із віртуальною мережею
docker-compose down
