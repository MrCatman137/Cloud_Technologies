# Лабораторна робота №12: Автоматизований контроль стану сервісів (Healthcheck у Docker Compose)

Налаштування механізмів діагностики працездатності (healthcheck) для мульти-контейнерного середовища. Реалізовано перевірку готовності для in-memory сховища `redis` (`redis-cli ping`) та веб-сервісу `app` (ендпоінт `/health`), а також синхронізацію старту контейнерів за умовою `condition: service_healthy` для усунення збоїв під час ініціалізації.

---

### Команди для виконання та тестування

```bash
# 1. Валідація синтаксису конфігураційного маніфесту з блоками healthcheck
docker-compose config

# 2. Декларативний запуск середовища у фоновому режимі із контролем черговості
docker-compose up -d

# 3. Моніторинг переходу статусів контейнерів у стан healthy (Up (healthy))
docker-compose ps

# 4. Тестування HTTP-відповіді діагностичного ендпоінту та робочого функціоналу
curl -i http://localhost:8080/health
curl http://localhost:8080

# 5. Перегляд системних логів і фіксація автоматичних фонових проб Docker Engine
docker-compose logs

# 6. Коректна зупинка процесів і повна утилізація виділених мережевих ресурсів
docker-compose down
